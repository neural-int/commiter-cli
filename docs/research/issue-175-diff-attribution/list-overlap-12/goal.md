# 一覧完了後と一覧中開始の比較

## Goal

本文取得最大4worker、100件ページ、1応答300MB、同じ段階的メモリ保護・対象・期間・保存Git入力で、一覧完了後方式と一覧中開始方式を各1回比較する。

## Implementation

pipeline100x4は一意なTurnを容量16のqueueへ順次渡す。同一Turnのページは逐次取得し、結果は列挙順へ戻す。一覧用接続もRSS監視対象。本文worker最大4に加え一覧用接続が同時に存在し得る。列挙が失敗・競合した場合は本文証拠を保守的に破棄し、完全取得にはしない。既定は変更しない。
