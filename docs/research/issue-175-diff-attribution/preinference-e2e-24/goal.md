# 実App Serverから推論直前までのE2E確認（2026-10-24）

## Goal / Decision

実App Server→現在Git差分との照合→Grouping/Category/Text入力→helper stdinまでを、モデル推論なしで確認する。結論は、3フェーズの送信経路は通ったが、実履歴本文の到達は未達。実履歴を含むE2Eの成功とは判定しない。

## Conditions

通常CLIのgenerateCommitPlanと実gitstate.Collect、実historyattribution.Collect、実App Server JSON-RPC、実MLXクライアントの子プロセス通信を使用した。helperだけ受信専用プロセスへ差し替え、モデルストアには検証用メタデータを使用した。受信専用プロセスは入力を保存し、次フェーズを構築するためだけに固定のGrouping/Category/Text応答を返す。これらの応答は推論結果ではない。モデル読み込み・ダウンロード・推論・コミットは0回。

100件ページ、本文最大4並列、通常経路の取得期限5秒、1応答300MBとメモリ保護、現在ワークツリーだけを対象とする条件は変更していない。GitのHEAD/branch/index/対象変更の前後一致を確認。全CLI引数・設定読み込みからの起動ではなく、通常生成関数からのETLとhelperプロトコル送信を検証した。Swift製モデルhelper内部の受信・モデルロードは対象外。

## Validation

実履歴が空・候補0件の場合に成功しない明示実行専用TestLiveHistoryPreInferenceETLと、推論を行わないTestPreInferenceReceiverProcessを追加した。通常のテスト実行では実履歴テストをskipする。受信原本はリポジトリ外の新規0700ディレクトリ、各ファイル0600へ保存した。原本は保持し、本報告には本文・出典ID・個人パスを含めない。

成功: 既存CLI ETLの正常/重複/曖昧/取得不能/取得中変更ケースおよびキャッシュ・固定入力検査の回帰テスト、go vet ./internal/cli、git diff --check。回帰テスト16.166秒。

失敗として記録: 実履歴のある入力が3フェーズへ届くことを要求するライブテスト。01/02/03いずれもcontext0件なので成功扱いにしない。03では全フェーズの検査結果を記録してから失敗する。

## Next / Scope
