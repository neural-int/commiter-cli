# 履歴取得の時間無制限・推論前E2E計測（2026-10-25）

## Goal / Decision

前回5秒の期限に達した通常経路の履歴取得について、時間制限だけを外して1回測定した。取得は20.101秒でcompleteになった。ただし対象の編集操作は0件でno_related_evidenceとなり、実履歴を含むhelper入力の到達確認は未達。取得が完了したことと、必要な履歴を得られたことを分けて記録する。

## Conditions

前回と同じ現在チェックアウトの.gitignore変更1ファイルを対象に、通常のgitstate.Collect→generateCommitPlan→historyattribution.Collect→3フェーズの入力生成→helper stdinを使用した。raw_diff SHA256は前回と同一。App Serverは実プロセス、helperだけ推論を行わない受信専用プロセスに置換した。固定応答は次フェーズの構築のためだけに使い、推論結果とは扱わない。

Goのbuild overlayで、CLIの取得用contextと共通Collectのcontextにある2箇所の5秒期限のみをWithCancelへ置換した計測バイナリを作った。元ソース・通常CLIの設定は変更していない。テスト自体の時間制限も無効にした。現在ワークツリー限定、HEAD時刻から開始時刻までの期間、100件ページ、本文最大4並列、一覧と本文の重複実行、接続再利用、1応答300MB、メモリ保護、安全性フィルタは維持。Git固定確認用の期限と後続生成フェーズの予算は変更していない。

これはライブ履歴の1回測定であり、前回と履歴集合を固定した速度比較ではない。処理開始までに増えた会話は対象期間に入り得る。
